## `n_465f2abf8ca82a3a9ed20d0c` Groups

Groups are a filtering tool that displays pre-configured Kanban groups by assigning hashtags to individual Kanbans in the Qursor Configuration Application, allowing users to filter and call specific marked Kanbans in the Tablet Application.
