# Kanbans

The Kanbans menu provides a centralized interface for managing production Kanbans through dedicated tabs for filtering, viewing current status, and triggering execution. It includes specific controls for selecting Kanbans via groups or hashtags, monitoring running processes, and modifying their status or details.

## `n_32c42091be540a1c7a192e01` Current tab

The 'Current tab' interface displays currently running Kanbans and provides controls for managing them. Users can click the eye icon to view detailed step information or the cog icon to access settings for modifying status, removing, or advancing the Kanban.

## `n_820b616a5398b09f6f5ddecb` Trigger tab

The Trigger tab displays a scrollable list of Kanbans available for triggering within the current configuration. It supports filtering through pre-configured groups and hashtags, allowing users to select specific Kanbans for execution via the Trigger menu.
