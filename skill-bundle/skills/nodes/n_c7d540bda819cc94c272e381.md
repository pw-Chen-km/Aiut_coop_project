# Manual control

This section explains how to manually control an AGV using the HMI application. It covers raising and lowering pins and plates, as well as steering the vehicle with a joystick in Manual or Setup modes.

## `n_08a7c2b83658b297c109de5d` How to steer the AGV with the application?

In Manual or Setup mode, users can control the AGV locally via the AGV HMI application by pressing Request control in the Manual control tab to raise/lower pins and plates and steer using the joystick.
