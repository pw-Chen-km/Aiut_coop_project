# Diagnostic of AGV

The section describes the AGV diagnostic tab, which allows users to search and sort AGVs by name and access detailed diagnostic data. It includes features for viewing blackbox sensor previews, tracking battery levels, checking AGV positions on a map, and reading system notifications. Users can navigate between the main view, detailed information, and blackbox preview modes.
