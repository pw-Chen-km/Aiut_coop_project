# How to run a task?

The section explains that tasks are performed at stations with types assigned in the Configurator application. It describes the process of selecting a station in the Dashboard view, which triggers the call of the nearest unloaded AGV and displays the new task in the Tasks window. The text notes that the station is marked as reserved while awaiting the AGV, the destination path is shown on the map, and provides an example of a call and transfer task configuration.
