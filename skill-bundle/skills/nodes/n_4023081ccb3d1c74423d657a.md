This section outlines the administrative configuration of Hector zones by Qursor users, detailing the use of the zones configurator for defining parameters and visual polygons. It explains the integration with Navithor maps through zone ID placement and ID mapping via the zones.json file, while highlighting operational limitations and sensitivity regarding map modifications.
