# How to run a task?

The section explains that tasks are performed at stations with types assigned in the Configurator application. It describes the process of selecting a station in the Dashboard view, which triggers the call of the nearest unloaded AGV and displays the new task in the Tasks window. The user selects a specific task, such as call and transfer, causing the station to be marked as reserved and the destination path to appear on the map.
