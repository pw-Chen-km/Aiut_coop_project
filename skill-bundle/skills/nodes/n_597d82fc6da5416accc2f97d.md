## `n_26adb8fd61ea7b279e116f15` Main dashboard - Map

The map is a central element of the Dashboard view that displays the current position of AGVs, available paths, and stations. Users can navigate by holding the left mouse button to move, scrolling to zoom, and holding the right mouse button to rotate. The map may include optional zones such as lock zones and traffic light zones, with station statuses indicated by specific colors for enabled, disabled, or in-operation states. Additional features allow visualizing navigation scanners, heat maps, saving views, toggling layers, and adjusting the view scale or focus.
