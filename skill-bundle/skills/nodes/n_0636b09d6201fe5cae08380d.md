# Traffic-zones-configuration-1.2

This user manual documents the configuration of the Qursor platform's Hector connector, detailing the definition and management of 2D polygon zones for AGV traffic control. It explains the operational logic of traffic light zones for signal activation and lock zones for separating AGV and unmanaged vehicle areas, including procedures for manual overrides. The guide further covers the administrative setup of these zones using the configurator and their integration with Navithor maps via JSON mapping.
content_type: technical_documentation
