# Stations Choice Menu

The Stations Choice Menu provides an overview of all stations within a plant project, accessible via the navigation bar. It includes tabs for searching and selecting specific stations, monitoring and controlling station statuses, and viewing current or historical task logs.
content_type: navigation
question_intents: How to manage and monitor stations

## `n_1c9755a712794a022cb23552` Station choice tab

The section describes how to search for a specific station using the search bar, sort stations alphabetically, and select a station by clicking its button.

## `n_e0518e627094a5db24bb0228` Details tab

The Details tab provides a universal view for monitoring and controlling station statuses, illustrated by the A1 station. It includes an overview of specific control buttons for actions such as disabling the station, switching to autonomous mode, and viewing tasks.
