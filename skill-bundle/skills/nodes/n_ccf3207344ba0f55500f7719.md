# AGV - HMI Interface

The HMI control for the AMR Formica is accessible via a built-in touch-screen or a remote mobile application, with both methods offering similar functionalities that differ primarily in menu access and manual control methods. The touch-screen interface specifically features main menu tabs, AGV serial number display, and joystick and brake controls within the Manual tab.
