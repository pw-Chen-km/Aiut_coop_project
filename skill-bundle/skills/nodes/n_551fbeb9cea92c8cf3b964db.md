# Change the system mode

The section explains how to switch the system mode between automatic and autonomous via a click action, noting that the current mode is displayed on the top bar. It defines automatic mode as allowing management by the Qursor M.A.P. system with tasks triggered at stations, and autonomous mode as restricting management to station triggers, tablet applications, or other automation systems, where tasks cannot be triggered within the Qursor M.A.P. application.
