# Current tab

The 'Current tab' interface displays currently running Kanbans and provides controls for managing them. Users can click the eye icon to view detailed step information or the cog icon to access settings for modifying status, removing, or advancing the Kanban.

## `n_3179d82c36e7af34a8844218` The eye button

The eye button allows users to view detailed information about the currently running kanban step. Clicking the icon reveals specific data points such as kanban steps, priority, assigned AGVs, checkpoints, station addresses, and time to empty.

## `n_4df412400e2be5d157226f08` The cog button

The section explains how to access the settings menu for a running Kanban by clicking the cog icon, which reveals buttons for removing the Kanban, returning to the overview, proceeding to the next step, and changing the Kanban status.
